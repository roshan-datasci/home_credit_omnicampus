# Home Credit Default Risk | GCI World 2026

## About the Project

This project focuses on predicting loan repayment difficulties using machine learning. It was developed as a practical data science project alongside my learning journey with **GCI World 2026 (September)** and the Omnicampus platform.

I was accepted into GCI World 2026 September following the selection process conducted by the Matsuo-Iwasawa Laboratory at the University of Tokyo. The program provides learning opportunities in data science, Python programming, statistics, and machine learning.

I applied these concepts to the Home Credit Default Risk prediction problem, building a classification model and submitting predictions to the Omnicampus competition platform.

## 🎯 Project Objective

The objective is to predict whether a loan applicant may experience difficulties repaying a loan.

This is a binary classification problem in which machine learning is used to identify patterns in applicant data and estimate credit risk.

Through this project, I explored how data science can be applied to a real-world financial problem and how model performance can be evaluated using a competition leaderboard.

## ⚙️ Methodology

The project follows a typical machine learning workflow:

1. **Data preparation** — Load and inspect the competition dataset.
2. **Preprocessing** — Handle missing values and encode categorical variables.
3. **Model development** — Train a Logistic Regression classification baseline.
4. **Model validation** — Evaluate predictions using the ROC-AUC metric.
5. **Prediction generation** — Generate predictions for the test dataset.
6. **Competition submission** — Submit predictions to Omnicampus and review the resulting score.
